🤬 Indian Gaali Generator

A fun and hilarious Indian Gaali Generator built using HTML, CSS, and JavaScript. 😂

Click the generate button and watch desi gaaliyan appear one by one with smooth animations!

✨ Features
🤬 Collection of funny Indian gaaliyan.
🔥 One-by-one gaali generation.
🎨 Modern dark neon UI.
✨ Smooth animations and transitions.
📱 Fully responsive design.
⚡ Lightweight and fast.
🚫 No external libraries required.

HTML5
CSS3
JavaScript (Vanilla JS)
